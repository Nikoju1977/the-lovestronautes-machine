Réparer la version de Lovestronautes Machine

Si ton application affiche encore V23, cette page permet de récupérer la version publiée sur GitHub Pages, sans supprimer les compositions enregistrées dans ton navigateur.

OUVRIR LA VERSION WEB La réparation supprime uniquement les anciens caches « lovestronautes » et désinscrit le service worker de cette application. Elle ne supprime pas localStorage, IndexedDB, tes réglages, tes projets, ni les fichiers importés. Une connexion Internet est nécessaire. Si un projet est important, télécharge sa sauvegarde avant de réparer.
